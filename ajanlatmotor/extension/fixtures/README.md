# Parser fixtures

These are SYNTHETIC pages written to exercise the three parser layers. They imitate the
shape of a mobile.de listing but are not copies of real pages.

Before go-live, save 2–3 real mobile.de pages by hand (Chrome → Save page as → "Webpage, HTML only")
into this folder as `real-listing-*.html` and add them to `test/parser.test.ts`.
No automated fetching of mobile.de.
